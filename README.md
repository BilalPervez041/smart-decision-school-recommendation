# 🏫 Smart Decision — School Recommendation System

A school discovery and recommendation platform that helps users explore schools based on location, ratings, and fee information.

## 📌 Project Overview

Smart Decision is designed to simplify school discovery by providing relevant school information in one place. The project integrates Firebase for real-time data and Google Maps for location-based discovery and navigation.

## ✨ Key Features

- 🏫 School discovery and recommendations
- 📍 Location-based school exploration
- ⭐ School ratings
- 💰 School fee information
- 🔥 Firebase real-time data integration
- 🗺️ Google Maps navigation

## 🎯 Objective

To make school discovery easier by helping users explore available schools and compare relevant information.

## 🛠️ Technologies Used

- Firebase
- Google Maps
- Location-based services
- School recommendation logic

## ⚙️ Basic Workflow

1. Explore available school information.
2. Find schools using location and relevant criteria.
3. Review available ratings and fee details.
4. Use Google Maps to navigate to a school.

## 🚀 Project Status

Developed as a school discovery and recommendation project.
